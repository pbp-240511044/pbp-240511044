 # Analisis Komparatif Platform: Web, Desktop, dan Mobile

Berikut adalah tabel analisis komparatif yang membandingkan karakteristik platform Web, Desktop, dan Mobile berdasarkan berbagai aspek pengembangan perangkat lunak:

| Aspek | Web | Desktop | Mobile |
| :--- | :--- | :--- | :--- |
| **Bahasa Utama** | HTML, CSS, JavaScript (TypeScript)[cite: 2] | C#, C++, Java, Python, Swift[cite: 2] | Kotlin, Swift, Java, Dart, JavaScript[cite: 2] |
| **Arsitektur** | Client-Server (SPA/MPA), berbasis *browser*[cite: 2] | Standalone / Monolitik / Client-Server lokal[cite: 2] | Mobile App Architecture (MVC, MVVM, Clean Architecture)[cite: 2] |
| **Cara Distribusi** | Melalui *web server* / *hosting* dan diakses via URL *browser*[cite: 2] | Melalui instalasi file lokal (`.exe`, `.msi`, `.dmg`) atau *App Store*[cite: 2] | Melalui toko aplikasi resmi seperti Google Play Store dan Apple App Store[cite: 2] |
| **Keunggulan** | Tidak perlu instalasi, mudah diakses lintas *platform*, pembaruan terpusat di *server*[cite: 2] | Performa tinggi, dapat memanfaatkan *hardware* secara optimal, bisa berjalan tanpa koneksi internet[cite: 2] | Sangat portabel, terintegrasi penuh dengan fitur perangkat keras (GPS, kamera, sensor)[cite: 2] |
| **Keterbatasan** | Bergantung pada koneksi internet, akses terbatas ke fitur *hardware* tertentu[cite: 2] | Membutuhkan proses instalasi manual, pembaruan aplikasi harus dilakukan secara berkala oleh pengguna[cite: 2] | Batasan ukuran layar, fragmentasi perangkat yang tinggi, proses *review* rilis aplikasi yang ketat[cite: 2] |
| **Contoh Aplikasi** | Google Drive, Trello, Netflix[cite: 2] | Microsoft Office, Adobe Photoshop, VS Code[cite: 2] | WhatsApp, Instagram, Google Maps[cite: 2] |
